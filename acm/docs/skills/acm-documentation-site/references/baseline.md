# 保存した基準

このテンプレートは、ACM_websiteの`main`にあるコミット`e0bcd7f`時点のNIGHTOVERとACM VHS Simulatorを監査して作成した。後日デザインを変更するときは、現行コードを確認したうえでこの基準も更新する。

## NIGHTOVERから残したもの

- 情報量が多くても落ち着いて読める、装飾を抑えたドキュメントの外枠。
- 画面構成、作品管理、執筆機能、資料、解析支援、履歴、保存、設定というデスクトップアプリ向け分類。
- リリース情報、体験版と製品版、利用規約を独立ページとして扱う例。
- ロゴがある製品のヘッダー例。
- 対応バージョンの横並び表示。

## VHSから残したもの

- テキストだけの製品名でも成立するヘッダー。
- モバイルドロワーの背景、`inert`、`aria-hidden`、Escape、フォーカス復帰。
- RouterLinkと`aria-current`を使った左ナビゲーション。
- 検索結果にカテゴリ、見出し、説明を表示する構造。
- プリセット、加工前画像、比較画像、動画比較の例。
- 全項目早見表と機能グループ別詳細を分離する例。
- パラメータの範囲、初期値、効果、調整目安、関連項目を近接表示する例。
- 用語集、症状別の「想定される問題」、非操作の範囲メーター、モバイルカード表。

## テンプレート側で統一したもの

既存2ページは成熟後に別々に作られたため、次の実装差が残っている。新規ページではテンプレート側の仕様を使う。

- 左ナビはRouterLink＋`aria-current`。
- 検索は`/`と`Ctrl/Cmd+K`の両方を受け付ける。
- モバイルナビはVHS側のアクセシビリティ仕様を採用する。
- ナビ、検索、右目次、前後リンクを、1つの順序付きページ定義から派生させる。
- 不明なpage idと旧page idは正規URLへ置換する。
- スクロール先頭復帰は同期watch、ページタイトルとhash展開は遷移後watchへ分離する。
- アンカー余白は90pxへ統一する。
- 本文は常にarticleの最大760pxラッパーへ入れる。

## 商品固有のまま残したもの

- NIGHTOVERの暖色テーマ、ロゴ、作品管理・小説執筆向け本文。
- VHSの寒色テーマ、動画同期、比較スライダー、再読み込み、プリセット画像、パラメータカード。
- 個別商品のリリース情報、規約、用語、対応環境、画像、映像、パラメータ値。

共通化の目的は「同じ製品に見せること」ではなく、「どの製品でも迷わず読める位置と挙動を保つこと」である。
