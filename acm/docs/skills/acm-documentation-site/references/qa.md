# 検証チェックリスト

## 内容

- 対応OS、ホストバージョン、製品バージョン、範囲、初期値を一次資料と照合した。
- 実装・ビルド情報と内部試験記録を一般向け本文へ混ぜていない。
- 用語だけで効果を説明していない。見た目または操作結果が書かれている。
- 重複ページ、情報が増えない詳細リンク、名前だけの一覧がない。
- 未完成のスクリーンショット枠、仮文言、商品固有でないサンプルがない。

## 構造

- 全ページのパンくずx/y、H1 x/y、本文幅が一致する。
- 短いページでスクロールバーが消えても横位置が変わらない。
- 対応バージョンはNIGHTOVERと同じ横並び。
- 右目次の項目が実在する見出しidと一致する。
- 前後リンクが左ナビの順序と一致する。
- 検索結果の遷移先で情報が実際に増える。

## 遷移

- 深くスクロールしたページから別ページへ移動し、0ms、16ms、60ms、180ms、400msで`scrollY`が0のまま。
- hash付きリンクは該当見出しを固定ヘッダーの下へ表示する。
- 戻る／進むでページ、見出し、タイトルが一致する。
- モバイルメニューを開いたままページ移動しても閉じる。

## レスポンシブ

少なくとも次を確認する。

- 1280×720: 3カラム。本文最大760px。
- 1024×768: 2カラム。右目次なし。
- 390×844: 1カラム。ドロワー、カード化した表、折り返し、横はみ出しなし。
- 長い日本語、英語UI名、範囲表記が1文字ずつ縦積みにならない。
- 横スクロール表は表の中だけでスクロールし、ページ全体を横へ押し出さない。
- 表の行を薄い交互色で追え、項目名から値まで視線を大きく折り返さず読める。

## 操作とアクセシビリティ

- 検索、メニュー、前後リンク、ページ目次をキーボードで操作できる。
- Escapeでモバイルメニューとライトボックスを閉じられる。
- 閉じたモバイルナビへTabフォーカスが入らない。
- 画像altが見た目と比較内容を説明し、captionと無意味に重複しない。
- `prefers-reduced-motion` で不要なアニメーションを止める。

## ビルドと差分

ACM_websiteの`acm`ディレクトリで実行する。

```powershell
node docs/skills/acm-documentation-site/scripts/validate-template.mjs
# 生成後は実ファイルも検証する
node docs/skills/acm-documentation-site/scripts/validate-template.mjs --page src/pages/ProductPage.vue --data src/data/product.ts --router src/router/index.ts
npm run build:alus
npm run build:rapro
git diff --check
```

ブラウザで実測してから、意図したファイルだけをstageする。既存の未追跡ファイルは含めない。
