# 商品別コンテンツモジュール

共通シェルへすべての機能を載せず、必要な商品だけがモジュールを追加する。データ型は`assets/product-documentation.modules.template.ts`を基準にする。

## プリセット

- 名前だけで終わらせず、仕上がりと向く素材を必須にする。
- 比較画像がある場合は、加工前画像も確認できる導線を付ける。
- captionは「どこを見ると違いが分かるか」を書く。
- プリセットにないカスタム例は、プリセット名を装わず「カスタム設定」と明示する。

## パラメータ

- `role`を本文の中心にし、値を上げ下げしたときの見た目を書く。
- `guide`と`related`は別カードにせず、説明文の後ろへ続ける。
- `range`と`defaultValue`は同じ視線範囲に置く。
- 数値範囲は操作できないメーター、離散値は選択肢の列として表示する。input rangeは使わない。
- モバイルではカードを1列化し、日本語が1文字ずつ折り返される列を作らない。

## 用語集

- 本文中で繰り返し現れ、初見で見た目を想像しにくい語だけを載せる。
- 日本語名、実UIの英語名、見た目との関係、検索用別名を持つ。
- 一般定義と製品内の効果が異なる場合でも「このサイトでいう」とは書かず、製品の処理として直接説明する。

## 想定される問題

- 見出しは原因名ではなく、利用者が見ている症状にする。
- 回答は確認箇所と対処を一続きで書く。「確認手順」「再現範囲と制限」を機械的に分けない。
- 同じ対処になる症状は1項目へまとめる。

## リリース情報

- 新しい版を先頭へ追加する。
- 版数、公開日、要約、追加・変更・修正など必要な区分だけを持つ。
- 内部チケット番号、ビルドログ、試験の全記録は載せない。

## 比較メディア

- 動画比較、同期処理、リフレッシュボタンは製品固有モジュールとして追加する。
- 自動再生は`prefers-reduced-motion`を尊重する。
- ループ境界で同期補正を繰り返さず、再生不能時に利用者が再読込できるようにする。
- 比較ハンドルの矢印やラベルは`user-select: none`。
- 動画へ画像用ライトボックスを適用しない。
