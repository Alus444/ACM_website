# 共通ドキュメント構造

NIGHTOVERとACM VHS Simulatorで揃えるのは、色や商品固有の見せ方ではなく、ページを読んで移動するための骨格である。

## 画面構造

```text
64px 固定ヘッダー
└─ 最大1350pxの3カラム
   ├─ 左ナビゲーション: 270px
   ├─ 中央コンテンツ: 最大860pxのカラム内に本文最大760px
   └─ 右ページ目次: 220px
```

- ヘッダーは高さ64px、`position: sticky; top: 0`。
- `.docs-layout` は `width: 100%`, `max-width: 1350px`, `margin: 0 auto`。
- 3カラムは `270px minmax(0, 860px) 220px`。
- 中央カラムの外側余白は `48px clamp(34px, 4vw, 64px) 60px`。
- パンくず、ページ見出し、本文、前後リンク、フッターは最大760pxで中央揃え。
- パンくずとH1はすべてのページで同じ `.page-heading` に置く。概要ページだけ別の上余白を持たせない。
- 左ナビゲーションは `top: 64px`, `height: calc(100vh - 64px)` のsticky領域。検索、ページ群、対応バージョンの順に並べる。
- 対応バージョンは「対応バージョン」と「Ver.x」を横並びにし、左右へ分離する。
- 右目次は現在ページのH2/H3だけを表示する。ページ全体のナビゲーションを重複させない。
- `html` に `scrollbar-gutter: stable` を指定し、短いページでスクロールバーが消えても横位置を変えない。

## ブレークポイント

- `1180px以下`: 最大1110px、`250px minmax(0, 860px)` の2カラム。右目次を非表示。
- `820px以下`: 1カラム。左ナビゲーションを固定ドロワー化し、メニューボタンを表示。
- `600px以下`: 本文左右余白を約17–18pxへ縮小。前後リンクや複数列カードを1列化。
- 横幅不足で表の各列を無理に縮めない。一般的な情報表はモバイルでカード化し、列関係の維持が必要な表だけ横スクロールを使う。
- 表の行背景はごく薄い交互色にし、罫線だけを追わせない。項目名と値を近づけ、視線が大きなL字を描く配置を避ける。

## ページと経路

- 経路は `/<product-slug>/:page?` のhash route。
- 概要だけ `/<product-slug>`、ほかは `/<product-slug>/<page-id>`。
- 不明なpage idは概要へ置換する。
- ページ切り替えはコンポーネント側の `watch(activePage, ..., { immediate: true, flush: 'sync' })` で、hashがなければ `window.scrollTo({ top: 0, left: 0, behavior: 'auto' })` を即時実行する。
- `router/index.ts` の `scrollBehavior` はhashを優先し、ドキュメント経路では `false` を返す。遅れて発生するRouter側スクロールと競合させない。
- hashリンクは固定ヘッダーを避けるため上余白84–90pxを確保する。
- 前後ページは左ナビゲーションと同じ一次元順序から算出する。

## 検索

- 左ナビゲーション上部に1つだけ置く。ヘッダーに重複させない。
- ページ名だけでなく、見出し、説明、別名、用語、症状を検索対象にする。
- 結果からページと該当見出しへ直接移動する。
- PCでは `/` または `Ctrl/Cmd+K` のどちらかを製品内で一貫して使用する。フォーム入力中は `/` を奪わない。
- モバイルでは検索フォーカス時にドロワーを開く。

## モバイルナビゲーション

- 開閉ボタンに `aria-expanded` と `aria-controls` を付ける。
- 閉じたドロワーは `aria-hidden` と `inert` で操作対象から外す。
- 開いたときは背景を固定し、背面クリックとEscapeで閉じる。
- 閉じた後はメニューボタンへフォーカスを戻す。

## 画像とメディア

- 静止画はfigure、説明的なalt、必要なfigcaptionを持つ。
- 拡大対象だけライトボックスを有効にする。動画はユーザーが明示的に求めない限り拡大対象にしない。
- ライトボックスはEscape、背景クリック、閉じるボタンに対応し、開く前の要素へフォーカスを戻す。
- 比較画像や動画には、何を比較できるかが本文またはcaptionだけで分かる説明を置く。
- スクリーンショットが未用意なら、壊れた画像や空の枠を公開本文へ残さない。
- 矢印は細い線だけにせず、`△`または`▷`系の先端が分かる表現を使う。装飾用の矢印や比較ハンドルは文字選択できないようにする。

## 共通と商品固有の境界

共通にするもの:

- 幅、余白、見出し位置、ブレークポイント
- 検索、左ナビ、右目次、前後リンク
- ページ遷移時のスクロール
- キーボード操作とライトボックスの基本アクセシビリティ
- 対応バージョン表示

商品固有にするもの:

- 色、ロゴの有無、製品名の組版
- ページ群と本文の順序
- パラメータ表、動画比較、作品管理表などの専門UI
- 用語集、トラブル対応、リリース情報、規約など、その製品に必要なページだけ
